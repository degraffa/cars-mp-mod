CarsMP adds 3 and 4 player split-screen and an uncapped frame rate, 144 fps by default, to the Steam release of Cars (2006, app 331160). It is one proxy DLL that patches the game in memory.

- [How It Was Built](How-It-Was-Built.md): the path from a 2-player game to a working 4-player race
- [Game Internals](Game-Internals.md): addresses and structures found along the way
- [Extending the Mod](Extending-the-Mod.md): how to add patches, hooks and test runs

Install steps are in the [README](../../README.md#install). Open work is in the [issues](https://github.com/degraffa/cars-mp-mod/issues).
